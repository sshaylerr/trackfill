# Trackfill

A pad sampler and synth workstation for the phone: one self-contained web page with a WebAssembly audio engine.

- Build: `./build.sh` (needs clang with the wasm32 target, python3 and node)
- Test: `node tests/run.cjs`
- Checks before a release: `notes/safety-pass.md`
- How it's put together, and where work stands: `notes/HANDOVER.md`
